## What I learned
- Files whose names start with a dot, such as `.gitignore`, are hidden by default on Unix-like systems. `ls` does not show them, but `ls -a` does
- `.gitignore` tells Git which files to leave untracked (build output, IDE settings, secrets such as `.env`). It should be in place before files are committed
- The MIT license lets others use, modify, and distribute the code as long as the original copyright notice is kept
- Docker packages an application and its environment into a container so it runs the same everywhere. Kubernetes manages many containers across many machines. I will use Docker and Docker Compose in this project, and only need Kubernetes at the conceptual level for now
